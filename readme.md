These reports are just for fun and to train building PowerBI reports and semantic models. 

The datasets, available on /sources/, are available online on platforms like [Microsoft Learn](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-datasets) and [Kaggle](https://www.kaggle.com/datasets). In some cases, I created additional dimensions to help me with the visuals or navigation options I intended to use.

See more project ideas [here](https://www.projectpro.io/article/power-bi-microsoft-projects-examples-and-ideas-for-practice/533).
